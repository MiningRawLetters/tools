# MRL Offspring

**Every font deserves offspring: save true-to-source copies under a new name, ready to grow on their own.**

## Features

- Lists every currently open UFO
- Pick which ones to spin off (checkbox)
- Set a new file name per font
- Optionally rename the family (font info) of the copy
- Original files are never touched — each offspring is a full disk copy, renamed after

## Usage

1. Open the font(s) you want to spin off in RoboFont
2. Launch **MRL Offspring** from the Extensions menu
3. Check the fonts you want, edit "New File Name" / "New Family Name" as needed
4. Click **Create Offspring**
