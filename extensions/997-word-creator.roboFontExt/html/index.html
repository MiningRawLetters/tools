997 Word Creator

997 Word Creator is a RoboFont extension that generates test words for type testing, spacing, and more. It allows you to create lists of words that match specific criteria, such as containing certain letters, matching specific patterns, or fitting within a specific range of lengths.

This extension is based on Nina Stössinger's excellent word-o-mat extension but follows a functional programming approach under the hood.

Note: To make the most of this extension, you should have a font open in RoboFont, especially if you want to limit results to characters in your font or sort words by width.

Basic Settings

  • Source: Choose the dictionary/language to use for word generation.
  • Number of words: Specify how many words you want to generate.
  • Min/Max length: Set the minimum and maximum word length in characters.
  • Limit to charset: When checked, only words containing characters in your font will be included.

Letter Filters

  • Required letters: Specify letters that must be present in the words.
  • All letters must be present: When checked, all required letters must appear in each word.
  • No letter repetitions: When checked, words with consecutive identical letters are excluded.

Advanced Filters

  • Match pattern (regex): Use regular expressions for more complex patterns.
  • Custom character set: Restrict words to only use characters from this set.

Output Settings

  • Case: Choose how to format the output (lowercase, UPPERCASE, Title Case, or RaNdOm).
  • Sort by: Sort words alphabetically, by length, or by width in the current font.
  • Sort order: Choose between ascending or descending order.

Examples

Goal Settings
Words containing 'q' but not 'u' Required letters: q
Match pattern: ^[^u]*$
Words with exactly three 'a's Match pattern: ^([^a]*a){3}[^a]*$
Words with both ascenders and descenders Match pattern: [bdfhklt].*[gpqyj]|[gpqyj].*[bdfhklt]
Words with no round characters Match pattern: ^[^oOpPbBdDgGqQcC]*$

Regular Expression Tips

  • ^ - Start of word
  • $ - End of word
  • [abc] - Any character from the set (a, b, or c)
  • [^abc] - Any character NOT in the set
  • .* - Any characters (zero or more)
  • .+ - Any characters (one or more)
  • \w - Any word character (alphanumeric + underscore)
  • {n} - Exactly n times
  • {n,m} - Between n and m times
