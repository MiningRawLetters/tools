# MRL String Library

A RoboFont extension for managing Space Center strings from categorized Markdown files.

**Developed by Kevin Kuhn (Mining Raw Letters)**

## Features

- 📁 **Organize strings by categories** in a simple Markdown file
- 🖱️ **One-click workflow** - Click any string to send it directly to Space Center
- 📝 **Easy editing** - Add and delete strings through the UI or by editing the file
- 🔄 **Live updates** - Changes to the Markdown file are reflected immediately
- 📋 **Preserves order** - Categories appear in the same order as your Markdown file
- 🔢 **Handles duplicates** - Duplicate category names are automatically numbered

## Installation

1. Download the latest release
2. Double-click `MRL_library.roboFontExt` to install
3. Restart RoboFont
4. Find "MRL Library" in the Extensions menu

## Usage

1. **First Setup**: Click the ⚙ button to select your Markdown file
2. **Select Category**: Choose from the dropdown menu
3. **Send to Space Center**: Single-click any string to send it instantly
4. **Add Strings**: Type in the input field and click "Add"
5. **Delete Strings**: Select a string and click "Delete"

## Markdown File Format

```markdown
# Lowercase
- n o h p d b
- a e i o u

# Uppercase  
- H O N P D B
- A E I O U

# Test Strings
- The quick brown fox
- Pack my box with five dozen liquor jugs
```

## Requirements

- RoboFont 3.0 or later
- A Markdown file with your string categories
